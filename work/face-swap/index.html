Face Swap Service

A FastAPI computer vision service that replaces faces across a video and keeps the original audio.

Role
Personal project
Year
2026
Area
Computer vision, API
Code
Private repository

Overview

Upload a reference face and a target video; the service detects the face, swaps it frame by frame, re-encodes the result and merges the original audio back in. A React front end and Docker Compose setup sit around the API.

Architecture

Hard parts

OpenCV drops audio

OpenCV writes video frames only. The pipeline writes an intermediate silent video, then uses FFmpeg to re-encode it and map the original audio stream back in.

Stack

  • Python
  • FastAPI
  • InsightFace
  • ONNX Runtime
  • OpenCV
  • FFmpeg
  • React
  • Docker

Known limits

  • Processing runs synchronously inside the request.
  • No authentication, rate limiting or automated tests yet.
