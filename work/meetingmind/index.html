MeetingMind

A desktop prototype that records a meeting, transcribes it, and drafts the summary, action items and follow-up email.

Role
Prototype
Year
2026
Area
Electron, speech, LLM
Code
github.com/J4dGPT/meetingmind

Overview

Built with Electron and React. Audio is captured from the microphone, transcribed with the Whisper API, and sent to Claude for a structured summary, action items and a follow-up draft. Results are stored locally and searchable.

Architecture

Hard parts

Structured output from free text

The Claude response is parsed into separate summary, action item and email fields so the UI can render and store them independently.
